# CodeSync — Collaborative IDE Concept

CodeSync is a concept showcase landing page for a collaborative web-based IDE. Built using HTML, CSS, and JavaScript, it presents the vision of a unified coding environment for developers, students, and teams.

This project focuses on the **UI, design, and presentation of the idea**, rather than a fully functional IDE.

## Live Demo

🌐 **[Explore CodeSync](https://akash-ide-web.netlify.app/)**

## Concept

CodeSync envisions a browser-based development environment that brings coding, collaboration, and communication together in one workspace.

The landing page showcases the proposed features and user experience of this concept.

## Highlighted Features

- **Collaborative Workspace:** A concept for shared coding and teamwork.
- **Live Coding:** A proposed real-time collaborative editing experience.
- **Integrated Terminal:** A planned terminal within the coding environment.
- **Voice and Video Chat:** Proposed communication tools for developers.
- **Shared Workspaces:** A concept for managing collaborative and personal projects.
- **Modern UI:** A clean, developer-focused interface presenting the idea.

> These are proposed IDE features showcased on the landing page, not implemented IDE functionality.

## Tech Stack

- **HTML5** – Page structure
- **CSS3** – Styling, layouts, and visual design
- **JavaScript** – Landing page interactivity

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/akashprabhu683/web.git
   ```

2. Navigate to the project directory:

   ```bash
   cd web
   ```

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for local development.

## Deployment

Deployed using [Netlify](https://www.netlify.com/).

**Live Demo:** https://akash-ide-web.netlify.app/

## Project Scope

This project is a frontend concept and landing page. It does not currently provide a functional code editor, real-time collaboration, terminal execution, or integrated voice and video communication.
